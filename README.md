# QB_Scouting
This project was created to provide a dashboard for scouting quarterbacks at the college level. Utilizing historic tracking and play by play data from PFF

<img width="2516" height="1163" alt="shinyscreenshot (11)" src="https://github.com/user-attachments/assets/07788320-2f91-432f-ba27-66de72a5eff2" />

The top row displays QB trackign data color coded by whether or not they were pressured on the given play. The visual is separated to display data based on the hash that the ball is spotted on at the snap. Below this we have the QB's passign statistics, also split by hash, to display efficiency throughout the selected games. The bottom left provides a summary of the QBs "escape routes", which is the direction the QB moves toward when he is pressured by the defense. This allows an opposing defense to game plan for cuting off scramble attempts and increasing pressure on the QB. Lastly the bottom right displays the location that the QB releases the ball from on 3rd down pass attempts. A The X mark displays the average location with a blue circle to display the 80% confidence interval
